# 審査依頼コメントのひな形（モネがPRごとにコメントする）

リポジトリに `AGENTS.md` を置かなくても、このコメントだけでCodex（アム）に審査基準を渡せる。
1回目のレビューで、Codexは `AGENTS.md` に書いていない 🔴🟡⚪ と「場所・問題・理由・修正案」の形式を、
PRコメントの依頼だけで守った（実績）。

```
@codex review

審査をお願いします。PR本文の「確認してほしい点」を中心に見てください。
- 指摘は 🔴必須（バグ・セキュリティ・要件未達・データ破壊・秘密情報の混入）／🟡推奨／⚪任意 に分け、各指摘を「場所・問題・理由・修正案」で1〜2行にする
- 初回に全部出し、小出しにしない
- コードと実行結果を自分で読んで判断し、モネの説明を鵜呑みにしない
- 2回目以降は、前回の🔴が直ったかと新しい変更だけ確認する
```
